# Introduction

Our very sophisticated `calc` library has the following functions:

## `constexpr add(int a, int b)`

Here is an example:

```cpp
using namespace calc;
assert_eq(add(1, 2), 3);
```

## `constexpr subtract(int a, int b)`

Here is an example:

```cpp
using namespace calc;
assert_eq(subtract(1, 2), -1);
```

## `constexpr multiply(int a, int b)`

Here is an example:

```cpp
using namespace calc;
assert_eq(multiply(1, 2), 2);
```
